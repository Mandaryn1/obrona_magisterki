# Bariery w przestrzeni cyfrowej – wprowadzenie

> **Źródło:** opracowanie oparte na materiałach z wykładów W0–W12 (dr inż. M. Miłosz, dr M. Dzieńkowski, Politechnika Lubelska, projekt „Projektowanie uniwersalne na Politechnice Lubelskiej"). Fragmenty oznaczone ***(uzupełnienie)*** pochodzą spoza wykładów (z mojej wiedzy lub z aktualizacji przepisów) – można je pominąć, jeśli prowadzący wymaga tylko treści z wykładu.

## O przedmiocie

- **Przedmiot:** Bariery w przestrzeni cyfrowej (kierunkowy/HES), I rok, 1 semestr, 30 h wykładu, 2 ECTS, zaliczenie (próg 51%).
- **Cele:**
  1. zapoznanie z szeroko rozumianą **dostępnością** w różnych sferach życia, w szczególności **dostępnością cyfrową**,
  2. zapoznanie z **projektowaniem uniwersalnym interfejsów** oraz metodami badania ich **dostępności i użyteczności**,
  3. wykształcenie **wrażliwości** na bariery, z którymi spotykają się osoby z niepełnosprawnościami.

| Wykład | Treść | Zagadnienie z listy |

## Słowniczek skrótów

| Skrót | Rozwinięcie / znaczenie |
| :--- | :--- |
| **PU** | projektowanie uniwersalne (universal design) |
| **HCI** | Human–Computer Interaction – interakcja człowiek–komputer |
| **UCD** | User-Centered Design – projektowanie ukierunkowane na użytkownika |
| **UX** | User eXperience – doświadczenie użytkownika |
| **WCAG** | Web Content Accessibility Guidelines – wytyczne dostępności treści internetowych (W3C) |
| **ARIA** | Accessible Rich Internet Applications – atrybuty poprawiające dostępność aplikacji webowych |
| **SUS** | System Usability Scale – skala użyteczności systemu |
| **SUM** | Single Usability Measure – jedna (globalna) miara użyteczności |
| **WUP** | Web Usability Points – metryka oceny jakości aplikacji webowej |
| **LUT** | lista kontrolna oceny użyteczności (obszary → podobszary → pytania) |
| **AOI** | Area of Interest – obszar zainteresowania (eyetracking) |
| **RTA** | Retrospective Think Aloud – wywiad z uczestnikiem po teście eyetrackingowym |
| **CAID** | Computer Aided Interface Design – narzędzia wspomagające projektowanie interfejsu |
| **UIDL** | User Interface Description Language – formalny język opisu interfejsu |
| **IEA** | International Ergonomics Association |
| **ISO 9241** | „Ergonomia interakcji człowiek–system" (m.in. 110 – zasady dialogu, 210 – projektowanie ukierunkowane na człowieka, 11 – definicja użyteczności) |
| **ISO 25062** | standardowy format raportu z testów użyteczności |
| **NCBiR** | Narodowe Centrum Badań i Rozwoju |
